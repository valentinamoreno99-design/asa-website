# Sapient Style Guide

Use the visual language of Publicis Sapient as inspiration.

Replicate:

• typography scale

• spacing rhythm

• section transitions

• hierarchy

• white space

• editorial composition

Do NOT replicate their colors, branding or content.

Apply the ASA brand identity instead.
